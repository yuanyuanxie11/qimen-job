# 奇门求职盘

**👉 欢迎使用网站：[https://yuanyuanxie11.github.io/qimen-job/](https://yuanyuanxie11.github.io/qimen-job/)**

很多时候在找工作时，我想问：这周会不会有面试？投的那家公司有没有戏？offer 能不能拿到、薪资能不能谈高？奇门求职盘用传统的时家奇门，在你提问的那一刻起一盘，专门从求职角度给出解读。

## 三步出结果

1. **写下你的问题**
   比如「这周会有面试吗？」「我对目标公司有没有机会？」
   也可以选填**出生年份**：网站会用你的「年命」代表你本人，同一时辰不同的人看到的结果也会不同。
2. **选择问题类型**
   网站会根据你的问题自动推荐类型、自动识别公司名，你也可以手动改。
3. **点击「起盘」**
   按你点击的那一刻排出九宫盘，右侧给出结论、应期（哪几天容易有动静）和行动建议。

## 能问什么

| 你想问 | 看盘重点 | 你会得到 |
| --- | --- | --- |
| **面试时机**：这周有面试吗？ | 景门（面试通知）、开门（机会） | 有没有面试、未来 7 天里哪几天最可能来消息 |
| **公司机会**：我对 XX 公司有没有机会？ | 开门（公司/岗位）、值符（决策层）与你的关系 | 机会大小、对方对你的态度、什么时候有回音 |
| **Offer 与薪资**：能拿到 offer 吗？薪资怎么样？ | 景门、丁奇（录取文书）、生门（薪资） | offer 把握、薪资是给得爽快还是要谈 |
| **求职方向**：接下来往哪找？ | 八个方位的吉凶、开门/生门的五行 | 有利的城市方位、适合的行业方向 |

每次解读都会附上具体建议，比如「找内推比海投有效」「提前准备压力面」「核实岗位真实性」。

## 小贴士

- **一事一占**：心里想清楚一件事再起盘，同一个问题不要反复起。
- **同一时辰盘相同**：两小时为一个时辰，同一时辰内起出的盘是一样的；填了出生年份后，解读会按你的年命因人而异。
- **出生年份只存在你自己的浏览器里**，不会上传到任何地方。
- **时间可以指定**：默认用你点击的那一刻；在「指定时间」里也可以选别的时间或切换北京时间。
- 页面自动适配手机和深色模式。

## 声明

本网站按传统术数规则自动生成解读，仅供娱乐与自我反思，不构成任何职业建议。简历、作品和面试准备永远比卦象重要，祝我们早日拿到心仪的 offer！成为the other candidate!
