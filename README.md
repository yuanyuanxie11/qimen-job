# 奇门求职盘

一个专看求职的时家奇门网页，三步出结果：

1. **写下问题**：比如「这周会有面试吗？」「我投的xxx公司有没有机会？」
2. **选择类型**：会根据问题里的关键词自动推荐类型，也会自动识别公司名，你可以手动改
3. **点击起盘**：按点击那一刻排盘（也可以指定时间），右侧给出结论、应期和行动建议

四种类型分别看这些用神：

| 问题 | 主看用神 |
| --- | --- |
| 这周有面试吗 | 景门（面试通知）、开门（机会）、时干（此事），附未来 7 天应期 |
| 我对某公司有没有机会 | 开门（公司/岗位）、值符（决策层）、日干（你）的生克关系 |
| Offer 与薪资 | 景门、丁奇（录取文书）、生门（薪资） |
| 求职方向 | 八宫吉凶排序给出有利方位，开门/生门五行给出行业倾向 |

纯静态页面，无依赖、无后端：双击 `index.html` 就能用，也可以直接部署到 GitHub Pages。

## 排盘规则

- **时家奇门 · 转盘 · 拆补法**
- 节气：截断 VSOP87 + 章动 + 光行差计算太阳视黄经，节气时刻与天文台公布值误差在 1 分钟内
- 年以立春为界，月以节为界，**23:00 换日**（子初换日）
- 元：日柱符头，子午卯酉为上元、寅申巳亥为中元、辰戌丑未为下元
- 中五寄坤二；八神用 值符·腾蛇·太阴·六合·白虎·玄武·九地·九天，阳遁顺排、阴遁逆排
- 标注：空亡（时旬）、驿马（时支）、门迫、六仪击刑、十干入墓
- 时区：默认按浏览器本地时间起盘，也可切换北京时间

## 解盘思路

每个用神宫按「门 + 门的旺衰 + 九星 + 八神 + 天地盘干格局 + 空亡/马星/门迫/击刑/入墓」计分，再加上日干宫（你）与用神宫的五行生克（对方生我最好、对方克我最难），综合得出结论、应期和行动建议。规则表都在 `js/interpret.js` 顶部，想按自己的流派改很方便。

## 本地运行与测试

```bash
open index.html        # 或直接双击
node test/test.js      # 历法与排盘回归测试
```

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 文件结构

```
index.html          页面
css/style.css       样式（自动跟随深浅色）
js/calendar.js      节气、四柱
js/qimen.js         排盘
js/interpret.js     求职解读
js/app.js           界面
test/test.js        测试
```

## 声明

一事一占，同一时辰起出的盘相同。本项目按传统术数规则自动生成解读，仅供娱乐与自我反思，不构成职业建议。
